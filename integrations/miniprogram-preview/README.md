# 小程序受控草稿预览接入

这是交给小程序前端的独立只读页面，尚未加入正式小程序路由，不能把 Node 检查当作微信真机验收。

1. 将四个 `preview.*` 文件放入开发工具专用分包页面；适配 `../../utils/config` 的 `API_BASE`（此处要求不含末尾 `/api`），仅在开发版/体验版提供入口，不放进普通用户导航。
2. 后台保存完整草稿后点击预览，复制 15 分钟凭据；在页面中粘贴。凭据放请求头，不放 URL、日志、永久缓存或分享链接。页面隐藏即清除。
3. 页面展示角色造型、表情和背景；完整的饰品定位、页面 Banner、商品详情与图集动画，需要前端按同一契约接入其渲染组件。后台网页预览可先核对饰品、背景和商品。
4. `GET /api/content/preview` 返回固定草稿快照；素材只使用 `/api/content/preview/assets/{id}` 并带 `X-Preview-Token`。所有操作均不调用领养、兑换、穿戴、养成 API。
5. 正式内容改为 `GET /api/content`；素材 `/api/content/assets/{id}`。`releaseId` 是缓存版本，切换角色按 `characterId` 查内容，不用商品 ID 关联 IP。
6. 当前生产后台通过 SSH 隧道访问，公网预览入口关闭。微信真机接入前需确定 HTTPS 域名并配置 request/downloadFile 合法域名；开发工具可用本机隧道做隔离预览。不要将管理口直接明文开放到公网。

穿戴接口与完整字段以 `../../openapi.yaml` 为唯一契约。账号旧 `user_skin` 权益仍由旧接口提供，前端保留旧展示；新 `wardrobe` 为增量权益，禁止以新列表为空删除旧权益。
